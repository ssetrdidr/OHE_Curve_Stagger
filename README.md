# 📲 Install App on Android (Google Chrome)

1. **Open given link in Chrome:**
2. **Tap menu:** Tap **⋮** (top-right corner).
3. **Select install:** Tap **"📲 Install and create a shortcut"**.
4. **Confirm:** Tap **Install** (or **Create Shortcut**).
